Confidentialité

Politique de confidentialité.

Cette page explique simplement quelles données peuvent être traitées lorsque vous consultez charlesberthou.fr.

Dernière mise à jour : 13 mai 2026.

Mesure d'audience

Le site utilise Google Analytics pour comprendre les pages consultées et les tendances de navigation. Ces données sont traitées sous forme de statistiques d'audience.

Outils locaux

Certains outils fonctionnent dans le navigateur. Le registre conserve les informations dans le stockage local de votre navigateur et propose un export CSV côté navigateur.

Liens externes

Certains liens renvoient vers LinkedIn, Kleo ou des outils tiers. Ces services disposent de leurs propres politiques de confidentialité.

IA Learning

La page /ialearning/ utilise Firebase pour les fonctionnalités d'authentification, de progression, de classement et d'équipes. Cette application est séparée du site vitrine.

Contact et droits

Pour toute question relative aux données personnelles, vous pouvez contacter Charles Berthou via son profil LinkedIn.
