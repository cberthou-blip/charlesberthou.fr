Confidentialité

Politique de confidentialité.

Cette page explique simplement quelles données peuvent être traitées lorsque vous consultez charlesberthou.fr.

Dernière mise à jour: 10 mai 2026.

Mesure d'audience

Le site utilise Google Analytics pour comprendre les pages consultées, les tendances de navigation et l'intérêt porté aux contenus. Ces données sont traitées sous forme de statistiques d'audience.

Données directement fournies

Le site vitrine ne propose pas de formulaire de contact interne. Si vous contactez Charles Berthou via LinkedIn ou une plateforme externe, les données transmises dépendent de cette plateforme.

Liens externes

Certains liens renvoient vers LinkedIn, GitHub Gist, ChatGPT ou Kleo. Ces services disposent de leurs propres politiques de confidentialité et de leurs propres mécanismes de suivi.

IA Learning

La page /ialearning/ utilise Firebase pour les fonctionnalités d'authentification, de progression, de classement et d'équipes. Cette application est séparée du simple site éditorial.

Contact et droits

Pour toute question relative aux données personnelles, vous pouvez contacter Charles Berthou via son profil LinkedIn.
