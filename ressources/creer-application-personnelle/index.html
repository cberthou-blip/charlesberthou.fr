Créer son application

Charles BerthouMis à jour le 22 octobre 2026

J’ai créé avec l’IA une application pour mes collections de films, séries et bandes dessinées, avec mes critères de classement et de suivi. Elle a été compilée à distance et installée sur mon iPhone, sans Mac. Le code et les données restent conservés.

À obtenir : Une application utilisable, son code et une sauvegarde de vos données.

Pour démarrer

Le parcours utilise React Native, Expo et EAS Build. L’installation demande un compte Expo et l’enregistrement de l’iPhone. Un dépôt GitHub privé conserve le code. Vérifiez les conditions et coûts avant l’installation.

Sur ordinateur, collez le prompt dans Work ou Codex. Commencez par un aperçu testable. Le parcours iPhone décrit ensuite nécessite un compte Apple Developer Program payant.

  • Quelques éléments de votre collection et trois actions prioritaires à réaliser
  • L’appareil visé, le budget et les limites des outils déjà essayés
Les outils et leurs accès
ChatGPT Work ou Codex
L’assistant écrit le code, exécute les vérifications disponibles et corrige à partir de vos essais.
React Native et Expo
Ces outils réunissent interface et fonctions de l’application dans un même projet.
GitHub
Un dépôt privé conserve le code et ses versions, sans données personnelles ni secrets.
Expo EAS Build
EAS compile à distance. La distribution interne iOS exige Apple Developer Program et un appareil enregistré. Vous effectuez les connexions ; l’assistant prépare la configuration.

Créer son propre outil de collection et l’installer

À vous d’essayer

1. À partir de cinq éléments fictifs, propose les champs, catégories, statuts et règles de progression de la collection. Décris les trois parcours prioritaires avec leurs écrans et un résultat vérifiable pour chacun. Fais valider cette première version avant de coder
2. Vérifie l’environnement. Pour une installation sur iPhone sans Mac, examine React Native, Expo et EAS Build. Explique les comptes, la signature Apple, les coûts et les conditions d’installation avant engagement
3. Crée une première version avec stockage local et export. Conserve le code dans le dépôt privé autorisé
4. Ajoute les fonctions retenues : import, métadonnées, scan, progression ou rappels. Vérifie les accès et les limites des dépendances
5. Teste les trois parcours, les doublons, la fermeture et la réouverture. Exporte les données fictives, restaure-les dans une copie de test et compare les éléments et leurs champs. Prévois les changements de format des données pour les mises à jour

Collez ce texte dans ChatGPT ou votre assistant IA, puis répondez à ses questions.

Les étapes

  1. Définir la première version

    À partir de cinq éléments fictifs de votre collection, l’IA propose champs, écrans et règles de classement. Vous retenez trois parcours, par exemple ajouter un titre, le retrouver et modifier son avancement. Un résultat attendu pour chaque parcours permet de juger la première version.

  2. Confier la création du projet

    L’assistant crée le projet Expo et React Native, le stockage local et l’export, puis conserve le code dans le dépôt autorisé. Il fournit un lien d’aperçu et précise les fonctions testables. Vous ouvrez ce lien pour essayer la première version.

  3. Faire corriger à partir des essais

    Vous testez ajout, recherche et suivi, puis décrivez les difficultés avec une capture et le résultat attendu. L’IA corrige et ajoute les imports, métadonnées, scans ou rappels retenus. Les fonctions du téléphone seront testées après installation.

  4. Valider la conservation des données

    L’IA prépare les vérifications de sauvegarde. Vous ajoutez et modifiez des données fictives, fermez puis rouvrez l’application, exportez et restaurez une copie de test. Contrôlez doublons, accents et dates avant d’importer votre collection.

  5. Configurer l’installation une fois

    L’assistant prépare la distribution interne EAS Build et vous guide pour enregistrer l’iPhone auprès d’Apple. Vous effectuez les connexions et validez les coûts. Il vérifie l’appareil dans la configuration de signature, puis lance la compilation.

  6. Installer et essayer sur iPhone

    Après compilation, vous ouvrez le lien ou QR code sur l’iPhone enregistré et suivez l’installation. Testez clavier, navigation, fonctions du téléphone et modes clair et sombre. Transmettez les messages d’erreur précis pour que l’IA corrige.

  7. À chaque version : préserver la collection

    L’assistant modifie le projet existant et prépare la nouvelle version. Vous sauvegardez, installez puis vérifiez vos données. Conservez le code précédent et une sauvegarde exploitable pour revenir sur un changement.

Les points à vérifier

  • Les fonctions ont été essayées sur le téléphone
  • L’import est contrôlé et une sauvegarde a été restaurée
  • Le code est conservé, les coûts connus et les mises à jour préservent les données

Mon conseil : Faites essayer très tôt les trois actions essentielles avec quelques éléments familiers. Les besoins apparaissent plus clairement dans l’usage que dans une liste de fonctions.
